# EVUDDY

Rider app. Frontend only — website APIs are not called yet.

Full official EVUDDY lockup (green EV, pink UDDY, tagline). Splash is light so the whole mark is large and readable. Login through documents keep the previous form chrome.

Splash → mobile → OTP → details → verified → KYC → documents → submitted.

OTP: any 6 digits. Documents: tap to mark attached.

```bash
git pull origin main
flutter pub get
flutter run
```

Full restart after this pull — not hot reload.
